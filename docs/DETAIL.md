# 局域网访问

P1 规则：来自本机回环（127.0.0.1/::1）的请求直接放行；远程设备仍需 owner 审批。
Desktop 的设置面板用显式管理请求头调用 `/lan-access`，避免被 CSRF 校验误伤。

把原生 DSH Web 界面转发到局域网 / 外部端口映射。访问者第一次打开时进入“等待批准”，
在 DSH 的 **设置 → 局域网访问** 里允许后才放行；已批准设备获得持久设备凭据，
可在同一页移除（立即撤销）。不启动第二套 UI，不代理 VPN/隧道；只负责认证与转发。

## 使用

1. 安装并启用本 bundle；
2. 浏览器打开 `http://<NAS>:8097`（或你的端口映射地址），会显示等待页；
3. 在电脑的 DSH Web（本机 8096）打开 **设置 → 局域网访问**，点击“允许”；
4. 设备刷新后进入原生 DSH Web；之后重启 DSH 不需要重新批准；
5. 在同一设置页移除设备即可撤销。

## 限制

- P1 仅 HTTP；需要 HTTPS 时在配置里预留 `tls.certFile` / `tls.keyFile`，尚未验收。
- 不限制来源 IP（支持外部端口映射）；安全边界只有设备审批与 DSH 本身。
- Web profile 的管理页从 owner 的 DSH Web（例如 `<DSH主机>:8096`）进入 **设置 → 局域网访问**；
  Desktop 的页面走 `dsh-app://`，请用本机回环管理页 `http://127.0.0.1:8097/__manage`；设备侧访问管理路径会被拒绝。
